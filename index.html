O que é HTML?

O HTML (Hypertext Markup Language) é a linguagem de marcação padrão para a criação de páginas da web.

Principais Tags de Texto

  • h1; a h6;: Cabeçalhos de seção.
  • p : Define um parágrafo.
  • mark : Usado para destacar texto.

Resumo de Atributos do Link (Target)

Atributo Descrição
_self Abre na mesma janela (padrão).
_blank Abre em uma nova janela ou guia.

Dica Rápida

Sempre use a tag meta charset="UTF-8" para garantir a acentuação correta.
